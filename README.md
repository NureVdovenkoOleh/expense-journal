# Журнал особистих витрат

Наскрізний проєкт з дисципліни «Програмування мовою Dart», варіант 3.

Основна сутність — **витрата** з полями: дата, категорія, сума, валюта,
спосіб оплати, примітка.

## Запуск

```
dart pub get
dart run
```

## Структура

- `bin/expense_journal.dart` — точка входу, лише виводить результат.
- `lib/expense_data.dart` — вхідні дані у вигляді константного списку рядків.
- `lib/expense_journal.dart` — бібліотека з логікою обробки.

Обґрунтування проєктних рішень буде додано по завершенні лабораторної
роботи 1.
